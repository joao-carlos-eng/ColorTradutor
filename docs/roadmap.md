# Roadmap

Este documento delineia o futuro do desenvolvimento do ColorTradutor.

## Fase 1: Estabilização (Concluída)
- [x] Criação da interface básica moderna.
- [x] Integração estável com Google Translate (via `deep-translator`).
- [x] Correção de compatibilidade com Python 3.14.
- [x] Lógica de alinhamento heurístico (agrupamento de artigos).
- [x] Documentação técnica inicial.

## Fase 2: Robustez e Funcionalidades
- [ ] Implementação de sistema de cache de tradução.
- [ ] Seleção dinâmica de idiomas (além de EN -> PT).
- [ ] Persistência do dicionário de cores por sessão.
- [ ] Suporte a tradução reversa (PT -> EN).

## Fase 3: UI/UX Premium
- [ ] Temas Dark/Light configuráveis.
- [ ] Exportação do texto traduzido e colorido para PDF/HTML.
- [ ] Histórico de traduções recentes.

## Fase 4: Performance e Escalabilidade
- [ ] Suporte a arquivos de texto longos (.txt, .docx).
- [ ] Integração opcional com modelos locais (quando houver suporte estável para Python 3.14).
