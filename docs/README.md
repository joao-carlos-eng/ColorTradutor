# ColorTradutor

ColorTradutor é um projeto Python que oferece uma abordagem visualmente impactante para a tradução de texto. O aplicativo destaca visualmente as palavras traduzidas, associando cores únicas a cada termo para facilitar a correlação entre o texto original e o traduzido.

## Tecnologias Principais

- **Linguagem**: Python 3.11+
- **Interface Gráfica**: Tkinter, `tkhtmlview`
- **Tradução**: 
  - Google Translate API (via `googletrans`)
  - Modelos de Deep Learning (Hugging Face `transformers`)
- **Gestão de Dependências**: Poetry

## Funcionalidades Atuais

- Interface simples para entrada de texto.
- Tradução de texto (Inglês para Português).
- Exibição de legendas coloridas com o mapeamento original-tradução.
